# Jaya Motors 🚗🔧

Landing page oficial para **Jaya Motors**, centro automotriz en San Francisco de Macorís, República Dominicana.  
Más de **17 años de experiencia** ofreciendo neumáticos importados, mantenimiento y servicios de calidad.

---

## 🌟 Características del Proyecto
- **Diseño responsivo**: Adaptado para móviles, tablets y escritorio.
- **Secciones clave**:
  - Inicio con hero message y CTA.
  - Nosotros: historia y valores.
  - Servicios: lista completa (gomas, aceite, balanceo, reparación de aros).
  - Trabajos: galería visual.
  - Contacto: ubicación, WhatsApp y teléfono.
- **Testimonios reales** de clientes satisfechos.

---

## 🛠️ Tecnologías Utilizadas
- **HTML5 / CSS3 / JavaScript**
- **Bootstrap** para estilos y componentes responsivos
- **GitHub Pages** para despliegue
